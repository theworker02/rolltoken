# rolltoken

Roll HTML/Markdown token fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/rolltoken/

## Install / run

```bash
git clone https://github.com/theworker02/rolltoken.git
cd rolltoken
node src/cli.js
node --test
```
